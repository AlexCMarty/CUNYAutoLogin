# Install CUNYAutoLogin
{: .no_toc }

**Browsers:** Firefox 140+ or Chrome / Edge 141+.
{: .fs-5 }

---

## Official stores

[Install from the Chrome Web Store →](https://chromewebstore.google.com/detail/cunyautologin/nkkoameonkenaahfjkkicaphfncjikin){: .btn-cta .btn-cta--primary }
[Install from Firefox Add-ons →](https://addons.mozilla.org/en-US/firefox/addon/cunyautologin/){: .btn-cta .btn-cta--primary }

You can easily install CUNYAutoLogin from the Chrome Web store or Firefox Add-ons. Just click one of the links above. The Chrome Web Store one works in Chrome, Edge, and other Chromium browsers. The Firefox Add-ons one works in Firefox, Librewolf, and other Firefox based browsers. Both update automatically so you always receive the latest features & security patches.

---

## After installing

Open the extension (puzzle-piece menu → pin CUNYAutoLogin if you want it visible). The sidebar walks you through first-time setup in about ten minutes. See the [FAQ](/faq/) if you get stuck, or [open an issue](https://github.com/AlexCMarty/CUNYAutoLogin/issues).
